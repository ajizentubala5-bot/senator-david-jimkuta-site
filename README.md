# Senator David Jimkuta Website

This is a simple starter website for Senator David Jimkuta, built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` – main page
- `styles.css` – design and layout
- `script.js` – small interactive features

## How to run locally

Open the project folder in VS Code, then use Live Server or run a local Python server:

```bash
cd C:\Users\DELL\Documents\senator-david-jimkuta-site
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish to GitHub Pages

1. Initialize git in the project folder.
2. Push to your GitHub repository.
3. In GitHub, go to Settings > Pages.
4. Select the main branch and save.
